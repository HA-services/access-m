# Support

Published by AXSync, www.axsync.com.

## How to get help

1. Email hunain@axsync.com, or use the Contact the Author option on the Odoo Apps Store page of this product.
2. Include: Odoo version and edition, module version, whether Odoo.sh or self-hosted, what you expected, what happened, and a screenshot or the server log lines if there is an error.

## What is covered

Defects in the delivered module and questions about how it behaves. Custom restrictions for third-party modules, other Odoo versions and other applications are separate work.

## Reporting a defect

Describe the steps to reproduce. For a restriction that does not apply, send the rule, the user, the model and the screen where the element should be hidden. Views from third-party modules can differ, so the technical name of the view helps.
