# Changelog

## 17.0.1.0.0 (initial release)

- Access control rules for selected users or for whole user groups, optionally limited to some companies.
- Hide menus, with everything below them.
- Per model: block Create, Edit, Delete, hide Archive, Duplicate, Export, Import and Add Property, hide the chatter, Send Message, Log Note and Schedule Activity, hide view types (list, kanban, pivot, graph, calendar, activity, map), hide reports and bound actions.
- Per field: Invisible, Read-Only, Required, remove the external link, No Create, No Create and Edit, hide in kanban cards, not exportable, with an optional condition on the record and optional enforcement on the server.
- Per record: extra domain filters for read, edit, create and delete separately, with an Own and Subordinates option based on the Reports To field of the user.
- Per view: hide individual buttons, tabs, filters and group-by options, with an optional condition.
- Whole-user switches: Read-Only User, Disable Developer Mode, Disable Login, Hide the Apps Menu Button.
- Global switches: hide chatter, import, export, Add Property, the filter button, Add Custom Filter and Add Custom Group everywhere.
- Access Control Manager group. Members and administrators are never restricted, so nobody can lock themselves out.
- Reports To field on the user form.
